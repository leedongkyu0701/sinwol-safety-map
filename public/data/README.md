# Published Data

검증을 통과한 브라우저용 정적 JSON을 이 디렉터리에 생성한다.

- `fire-water.json`: 소방용수시설
- `shelters.json`: 사용중 민방위 대피시설
- `aeds.json`: 고정형 AED
- `other.json`: Source별 ETL 결과를 병합한 기타 안전시설
- `metadata.json`: Source 및 OTHER dataset별 요약

Raw 공공데이터를 그대로 복사하지 않으며, Published Schema와 Audit을 모두 통과한 최소 필드만 제공한다.
